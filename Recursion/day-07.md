# Recursion

1. **Recursion -**
<br>
<br>
When a function calls itself until a specified condition is met.
<br>
<br>
*When the memory runs out (infinite recursion) the program throws an segmentation error which is called as **'Stack Overflow'***
<br>
<br>
*The condition which terminates recursion is called as **'Base Case'***
<br>
<br>
***'Stack Space'** Stores the yet to be completed functions*
<br>
<br>
*The condition which terminates recursion is called as **'Base Case'***
